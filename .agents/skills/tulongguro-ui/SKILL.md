# TulongGuro UI Design System

## Psychological Color Palette
- **Primary Brand (Navy)**: `#1E3A8A` (Dominant in Teacher UI)
- **Action/Success (Green)**: `#10B981` (Dominant in Student UI)
- **Insight/Highlight (Amber)**: `#F59E0B`
- **Background**: `#F8FAFC`
- **Typography**: `#334155`

## Core Principles
1. **Mobile-First**: Always design for small screens first, then progressively enhance for larger screens.
2. **Dual-Interface Paradigm**: 
   - **Teacher UI** must feel administrative and authoritative, leveraging Navy `#1E3A8A` heavily.
   - **Student UI** must feel engaging, rewarding, and gamified, using Green `#10B981` as primary actions.
3. **Accessibility**: Maintain high contrast ratios, ensure inputs are clearly bounded, and use Amber `#F59E0B` for specific targeted literacy interventions.
4. **Tailwind Centric**: Rely entirely on Tailwind classes based on this custom palette. Do not write arbitrary CSS unless necessary.
